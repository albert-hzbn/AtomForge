\chapter{Building atomic structures}\label{ch:builders}
\section{Common builder workflow}
Choose the appropriate command under \ui{Build}, supply a periodic reference where required, set parameters, inspect the preview, and run the build action. Use Load Reference in Nanocrystal, CSL, or Polycrystal; Load Structure or Model in Custom Structure; and Add Structure in Merge. These buttons open the shared file picker, while file drops remain available. Read status messages before saving the result. Source previews and generated previews serve different purposes: changing a parameter may update an illustrative preview while the atomic result still needs rebuilding.

Successful Build-menu results open in a new structure tab through the main application's builder callback, preserving the source tab. Merge uses this same new-tab route. Select the generated tab before saving or running another tool. Direct atom edits, Cell Sculptor, Dislocation replacement, and Interstitial insertion update the current structure instead. In the detailed controls below, ``updates the main scene'' refers to the displayed result; it does not mean that every builder overwrites the original tab.

Use modest cells first. Replicating a structure multiplies its atom count; a $10\times10\times10$ replication of a four-atom cell contains 4,000 atoms before cuts. Increasing all three dimensions by two multiplies the workload by eight. Once the geometry is correct, increase size and inspect boundary contacts. A builder does not automatically relax strained bonds or remove every physically undesirable local environment.

\section{Bulk Crystal}
\uishot{bulk-dialog.png}{0bp 0bp 0bp 0bp}{The Bulk Crystal dialog at its initial settings. Change the default H site to Cu and the default lattice parameter to 3.61 Angstrom for the FCC Cu walkthrough. The element button opens a periodic-table picker.}
\textbf{Purpose.} Generate a symmetry-expanded periodic crystal from lattice parameters and asymmetric-unit sites. Inputs are the crystal system, space group, cell dimensions/angles, and element/fractional-coordinate rows.

\textbf{Procedure.} Select one of the seven crystal systems and a compatible space group (1--230). Set independent lattice parameters; check constraints implied by the selected system. Add each crystallographically independent site using an element and direct coordinates. Use the row deletion or clear controls to remove unwanted defaults. Build, inspect the expanded sites, and save a periodic format.

Fractional coordinates are coefficients in $\mathbf r=f_a\mathbf a+f_b\mathbf b+f_c\mathbf c$. They are not distances in \angstrom. Equivalent positions are generated by symmetry; entering a full conventional basis as though every site were independent can duplicate sites. Inspect the final count and short contacts. Twenty-four centrosymmetric groups (Fd$\bar3$m, Pn$\bar3$m, I4$_1$/amd, P4/nmm and others) have two origin choices in the International Tables, and their site coordinates differ between them: Si in Fd$\bar3$m is at 0 0 0 in choice 1 and at $\tfrac18\,\tfrac18\,\tfrac18$ in choice 2. For these groups the dialog shows \ui{Origin choice} (\code{--origin 1|2}, default 1); match the choice of the source of your coordinates (most databases use 2), since the wrong one doubles or misplaces atoms. Rhombohedral groups use hexagonal axes. The result names the group and its origin choice.

\textbf{Worked examples.} FCC Cu with group 225, $a=3.61$ \angstrom, and Cu at $(0,0,0)$ gives four atoms. BCC Fe with group 229, $a=2.87$ \angstrom, and Fe at $(0,0,0)$ gives two. These examples exercise symmetry expansion; they do not determine a thermodynamically optimal lattice parameter.
\begin{lstlisting}
AtomForge --build bulk --system cubic --spacegroup 225 --a 3.61 --atom "Cu 0 0 0" --output cu_fcc.cif
AtomForge --build bulk --system cubic --spacegroup 229 --a 2.87 --atom "Fe 0 0 0" --output fe_bcc.cif
\end{lstlisting}
For lower-symmetry cells, set \code{--b}, \code{--c}, and angles \code{--alpha}, \code{--beta}, \code{--gamma}. Repeat \code{--atom} for independent sites. The space group fixes the crystal system, so \code{--system} may be left out (HCP Mg: \code{--spacegroup 194 --a 3.21 --c 5.21 --atom "Mg 1/3 2/3 1/4"} ); a \code{--system} that contradicts the group is refused. Coordinates within $10^{-6}$ of a simple fraction (halves to twelfths, such as 0.3333333) are taken as that fraction.

\section{Substitutional Solid Solution}
\textbf{Purpose.} Assign species to existing lattice sites with requested fractions. This changes chemical labels on a host structure; it does not search for a special quasirandom structure or optimise chemical short-range order.

\textbf{Procedure.} Open a host with enough sites to represent the composition, then choose \ui{Build > Substitutional Solid Solution}. Select the source and species percentages. The GUI uses at\%, with the final row automatically balancing the total to 100\%; the CLI uses fractions summing to one. Choose a fixed seed for reproducibility. Generate the alloy and check the resulting species counts before export. For small hosts, integer atom counts limit the achievable composition.

The example host is a $5\times5\times5$ repetition of conventional FCC Cu: 500 sites. The 70\% Cu / 30\% Ni assignment uses seed 42. Keep the same host atom ordering and seed when reproducing an assignment; changing the host can change which particular sites are substituted.
\begin{lstlisting}
AtomForge --build sss --input cu_host.cif --frac "Cu=0.7,Ni=0.3" --seed 42 --output cu_ni_alloy.cif
\end{lstlisting}
The menu is controlled by \code{ATOMFORGE_ENABLE_SSS_BUILDER}, enabled by default. A seed of zero in the CLI requests a time-dependent seed. After substitution, an external relaxation may be needed to account for atomic size mismatch.

\section{CSL Grain Boundary}
\textbf{Purpose.} Construct a coincidence-site-lattice bicrystal from a compatible cubic periodic reference. A coincidence index $\Sigma$ describes lattice coincidence, not a calculated grain-boundary energy.

\textbf{Procedure.} Load the reference cell in the grain-boundary dialog. Enter a rotation axis $[u\ v\ w]$ and select a supported $\Sigma$ and candidate boundary plane. Set the thickness/repetition of each grain, any gap and vacuum, and an overlap-removal distance. Build and inspect both the interface and periodic cell boundaries. Save the bicrystal and relax it externally before comparing energies.

\textbf{Controls.} The axis is a crystallographic direction. The plane selector chooses from generated candidates. The CLI's \code{--plane} is a zero-based candidate index, not a Miller index. \code{--uca} and \code{--ucb} control stacking repetitions for the two grains. \code{--gap} separates the grains; \code{--vacuum} adds vacuum on each side. \code{--overlap} removes close contacts using a distance in \angstrom; an excessive cutoff can delete desirable interfacial atoms.

\begin{lstlisting}
AtomForge --build gb --input cu_fcc.cif --axis "0 0 1" --sigma 5 --plane 0 --uca 3 --ucb 3 --overlap 1.5 --output cu_sigma5.cif
\end{lstlisting}
This manual's generated example contains 60 atoms. The small thickness makes it a geometry demonstration, not a converged boundary-energy supercell. If \code{--sigma} is omitted, candidate search uses \code{--sigmamax}; specify the exact value when reproducibility matters. \code{--conventional} skips the primitive-cell conversion. Check both lattice compatibility and the selected candidate before interpreting a failed build as a file-format problem.

\section{Nanocrystal: shape cuts}
\textbf{Purpose.} Fill a finite shape with atoms from a periodic crystal. Load a periodic reference, select \ui{Shape Cut}, choose a shape, set dimensions and centre, and use automatic replication unless you need explicit repetition counts. Build the nanocrystal and inspect the output bounding cell.

\begin{longtable}{p{.29\linewidth}p{.62\linewidth}}
\toprule Shape & Main dimensions \\ \midrule\endhead
Sphere & Radius. \\
Ellipsoid & Radii along the three local axes. \\
Box & Half-lengths along the three axes; full side lengths are twice these values. \\
Cylinder & Radius, full height, and cylinder axis. \\
Octahedron & Size parameter for the octahedral cut. \\
Truncated octahedron & Size and truncation parameters. \\
Cuboctahedron & Size parameter for the cuboctahedral cut. \\
\bottomrule
\end{longtable}
\ui{Auto-center from atoms} derives a centre from the reference. Manual centring changes which lattice sites intersect the boundary and can change surface termination and atom count. \ui{Auto-replicate} chooses enough source repetitions for the cut; manual repetitions that are too small truncate the intended object. \ui{Rectangular cell} and vacuum settings provide an enclosing output cell; this does not make a nanoparticle a bulk material.

\begin{lstlisting}
AtomForge --build nano --input cu_fcc.cif --shape sphere --radius 10 --vacuum 5 --output cu_sphere.xyz
\end{lstlisting}
The example contains 336 atoms. Use \code{--rx/--ry/--rz} for ellipsoid radii, \code{--hx/--hy/--hz} for box half-lengths, and \code{--cylradius/--cylheight/--cylaxis} for the cylinder. Explicit source replication uses \code{--repa}, \code{--repb}, and \code{--repc}; zero selects automatic sizing in the CLI.

\section{Nanocrystal: Wulff construction}
Select \ui{Wulff Construction} in the nanocrystal dialog. Add facet families, each with nonzero $(hkl)$ indices and a positive relative surface energy. AtomForge expands families using the reference symmetry, previews the bounding planes, and cuts the periodic crystal by the resulting shape.

\begin{enumerate}
\item Load the periodic reference and check its orientation and symmetry.
\item Add, for example, $(100)$ and $(111)$ families with illustrative energies 1.0 and 0.9. These are demonstration ratios, not material data.
\item Set \ui{Max radius (\angstrom)}. The implementation scales plane distances by energy ratios, placing the highest-energy family at this maximum distance. This control is not necessarily the circumscribed vertex radius of the final polyhedron.
\item Inspect the \ui{Wulff Plane View}; family colours help identify the contribution of each family. Remove redundant families or add missing ones as required.
\item Build the atomic nanocrystal. Inspect discrete surface termination separately from the continuous plane preview, then export.
\end{enumerate}
The construction requires a bounded intersection of planes. A family may disappear from the final shape when other planes enclose it. Energy ratios must come from comparable surface calculations if a physical equilibrium-shape interpretation is intended. Atomic discretisation can break an ideal continuous shape's apparent symmetry in a very small particle. The same construction is available through Python \code{af.wulff} and native \code{--build nano --shape wulff}; use repeated \code{--facet "h k l energy"} arguments for the families.

\section{Custom Structure from OBJ/STL}
\textbf{Purpose.} Fill a closed mesh with lattice sites. The mesh is a spatial boundary, not a collection of atoms. Use a watertight OBJ or STL, a periodic atomic reference, a physical scale, and an orientation.

\textbf{Procedure.} Open \ui{Build > Custom Structure}. Load/drop the reference and mesh into their corresponding inputs. Set the mesh scale in \angstrom\ per model unit, then adjust rotation or the Miller-direction alignment. Select enough replication to cover the mesh, set vacuum, and build. Inspect thin features and the atom count; a feature narrower than the lattice spacing may contain no sites.

\begin{lstlisting}
AtomForge --build custom --input cu_fcc.cif --mesh octahedron.obj --scale 12 --vacuum 5 --output cu_mesh.xyz
\end{lstlisting}
The included octahedron has six vertices at the positive and negative unit axes and eight triangular faces. At scale 12 it produces 224 Cu atoms in this example. No Blender installation is required. To use Blender, create a closed mesh, apply the intended object transforms before export, export OBJ/STL, and verify the scale in AtomForge. Inspect for holes, self-intersections, and reversed or inconsistent faces when the fill is missing or unexpected.

The CLI provides \code{--rotx}, \code{--roty}, and \code{--rotz} in degrees. \code{--miller "h k l"} aligns a crystallographic direction with $+Z$ and overrides Euler orientation. A crystallographic direction $[hkl]$ and a plane normal $(hkl)$ differ in a general non-cubic cell; choose the alignment convention deliberately.

\section{Shape Modeller (CAD)}\label{sec:shape-modeller}
\textbf{Purpose.} Carve a crystal into any shape, modelled as in CAD tools such as OpenSCAD: primitives combined by booleans, moved by transforms, hollowed, offset and repeated in patterns, with regions that give the atoms inside them another element. Typical uses are faceted and core--shell nanoparticles, nanoshells, tubes, Janus particles, sintering necks between particles, porous blocks, probe tips, notched fracture specimens and matrices with embedded precipitates. Unlike \ui{Custom Structure}, no mesh file is needed, and unlike the Cell Sculptor the shape is not limited to Miller-plane slabs.

\textbf{Procedure.} Open the crystal to carve (for example from \ui{Build > Bulk Crystal}), then \ui{Build > Shape Modeller (CAD)}. Start from \ui{Templates} or add commands from \ui{Insert}; the script is checked as it is typed, an error names its line, and the status line gives the shape's extent, its volume and the number of atoms of the open crystal it will hold. The section view cuts the shape along $x$--$y$, $x$--$z$ or $y$--$z$ at a chosen depth, with regions in their element colours. \ui{Carve} fills the shape with the crystal in a new tab (an open box with \code{vacuum} on every side); \ui{Add to Pipeline} adds the \code{build-shape} step instead. \ui{Export Surface (OBJ)} writes the shape's surface as a closed triangle mesh (marching tetrahedra on a grid of the mesh spacing) for figures or other programs.

\textbf{Modes.} \emph{Carve} repeats the open structure's cell over the shape and keeps the atoms inside; the shape's origin sits at the cell origin plus the \ui{Shape offset}, so moving the shape by a fraction of a lattice vector chooses which atom is at its centre. \emph{Keep}, \emph{delete} and \emph{select} use the structure's own atoms without repeating it, with the shape centred on the cell centre (or the atoms' centroid without a cell): \emph{delete} cuts voids, notches and pores into a periodic crystal, \emph{keep} trims a structure to the shape, \emph{select} selects the atoms inside for further steps.

\textbf{The script.} Statements end with a semicolon; \code{//} and \code{\#} start comments. Variables hold numbers or vectors (\code{R = 20;}) and arithmetic uses \code{+ - * / \^{}}, parentheses and the functions \code{sqrt}, \code{sin}, \code{cos}, \code{tan} (degrees), \code{asin}, \code{acos}, \code{atan}, \code{atan2}, \code{abs}, \code{min}, \code{max}, \code{pow}, \code{floor}, \code{ceil}, \code{round}, \code{exp}, \code{ln} and the constant \code{pi}. Operations act on the shape that follows them or on a block in braces, as in OpenSCAD. All lengths are in \AA; shapes are centred on the origin unless stated.

For example, a gold-cored copper particle with a channel, and a truncated octahedron:
\begin{lstlisting}
R = 14;

    sphere(r = R);
    rotate([90, 0, 0]) cylinder(r = 3, h = 2 * R + 2);
}

As a pipeline step: \code{build-shape script='sphere(r = 15); region("Au") sphere(r = 8);'} after a step that makes the crystal, or \code{Pipeline([Step("build-shape", \{"script": ..., "mode": "delete"\})])} in Python. Atoms count as inside when their centres are inside (the signed distance is at most zero), so a surface through a lattice plane keeps that plane; the tests compare every primitive, boolean, transform and pattern with the same carving done independently.

\section{Polycrystal}
\textbf{Purpose.} Populate a box with grains cut by a Voronoi partition. Inputs include a periodic reference, box dimensions, grain count, random seed, and optional orientations. The construction creates geometric grain boundaries; it does not optimise their energies.

\textbf{Procedure.} Load a reference, enter box lengths and grain count, set the seed, and choose orientations or random assignment. Generate, inspect the grain sizes and contacts, and save. Use orientation colouring when the output retains orientation metadata. Reopening a format that lacks grain metadata can preserve atoms while losing those colours.

\begin{lstlisting}
AtomForge --build poly --input cu_fcc.cif --sizex 25 --sizey 25 --sizez 25 --grains 4 --seed 7 --output cu_polycrystal.cif
\end{lstlisting}
This example contains 1,329 atoms. The CLI accepts repeated \code{--euler "phi1 Phi phi2"} triplets in Bunge convention, one per grain; unspecified orientations are random. Use the same seed, dimensions, reference, and ordering to reproduce a sample. Increase the box relative to grain count when grains become too small to have a meaningful crystalline interior.

\section{Amorphous Structure}
\textbf{Purpose.} Produce a random packing subject to distance constraints. Specify elements and counts, a mass density or explicit box, pair-distance constraints, and a seed. This is an initial configuration generator; random packing alone does not establish a realistic glass network.

\textbf{Procedure.} Add the required species/count rows. Set density in $\mathrm{g\,cm^{-3}}$ or explicit box dimensions. Check the minimum separation settings; overly strict cutoffs at a high density can make placement impossible. Set a fixed seed, generate, and inspect the reported inserted count and any placement failure. Relax or equilibrate the configuration with a suitable external method before structural or energetic claims.

\begin{lstlisting}
AtomForge --build amorphous --element "Si 40" --element "O 80" --density 1.5 --seed 7 --output sio2_pack.xyz
\end{lstlisting}
The example has 120 atoms with a 1:2 Si:O ratio. The deliberately low packing density is useful for demonstrating construction and is not a claim about silica's equilibrium density. \code{--boxa/--boxb/--boxc} override density-derived dimensions. \code{--mindist "Z1 Z2 distance"} adds a pair constraint using atomic numbers; \code{--covtol} controls the covalent-radius fallback; \code{--attempts} bounds placement attempts. If placement fails, examine the geometry and constraints before merely raising the attempt limit.

\section{Defect, lattice and nanostructure builders (command line)}
Seven further builders run from \code{AtomForge --build MODE --input FILE --output FILE} and from \code{atomforge.build(mode, ...)} in Python. \code{AtomForge --help MODE} lists every option.
\begin{itemize}
\item \textbf{vacancy} removes randomly chosen atoms, optionally of one \code{--element}, by \code{--percent} or exact \code{--count}. \code{--min-separation} keeps vacancies at least that far apart, measured through periodic images when the input has a cell. A fixed \code{--seed} reproduces the same vacancies. Requesting more vacancies than eligible atoms is an error, not a silent cap. The remaining atoms stay on their unrelaxed lattice sites; relax the result before computing formation energies.
\item \textbf{strain} applies a homogeneous deformation gradient to the cell while keeping fractional coordinates fixed. Give engineering components (\code{--exx} \ldots \code{--eyz}; the symmetric shear terms enter $F=I+\varepsilon$) or a full \code{--matrix}. The volume scales by $\det F$. Internal relaxation is not performed.
\item \textbf{primitive} reduces a periodic structure to its spglib-standardized primitive cell. The result may be rotated into the standard setting.
\item \textbf{surface} cleaves a slab parallel to the Miller plane $(hkl)$ of the input cell, with \code{--layers} repeats of the shortest out-of-plane lattice translation and \code{--vacuum} the gap between its top surface and the periodic image of its bottom one. The slab is oriented with its surface normal along the third cell vector. By default the input is first reduced to its primitive cell (fewer atoms per layer); Miller indices are converted to that basis so they always refer to the input cell. Layers are stacked along the true lattice translation, so close-packed stacking (for example fcc ABC) is preserved. For fcc, the exposed atoms of (111), (100) and (110) slabs have 9, 8 and 7 nearest neighbours.
\item \textbf{sqs} rearranges species on the fixed input lattice to a target composition (\code{--element "SYMBOL FRACTION"}, repeated) by simulated annealing that drives Warren--Cowley parameters of the first \code{--shells} shells toward zero. It is a local optimizer of short-range order, not a full cluster-expansion correlation match. Check the reported objective and the SRO table, and use enough sites and steps for the target composition.
\item \textbf{nanowire} cuts a wire periodic along cell vector \code{--axis} with a circular (\code{--sides} below 3) or regular-polygon cross-section of apothem \code{--radius}. The square cross-section box has side $2(\mathrm{radius}+\mathrm{vacuum})$, so neighbouring images are separated by about twice the vacuum. \code{--axis-repeats} lengthens the periodic cell.
\item \textbf{core-shell} relabels a finite structure: atoms closer than \code{--core-radius} to the centroid (or \code{--center}) become \code{--core-element}, the rest \code{--shell-element}. Positions are unchanged; relax mismatched core/shell lattices before analysis.
\end{itemize}

\section{Low-dimensional structures, clusters and molecules}\label{sec:low-dimensional}
These builders are pipeline steps in \ui{Build > Low-Dimensional} and \ui{Build > Clusters and Molecules}; they need no structure open, and each is also a step for \code{AtomForge --pipe} and Python (e.g. \code{AtomForge --pipe "build-nanotube 10 0 length=4" --input - --output cnt.xyz}).
\begin{itemize}
\item \textbf{Nanotube} (\code{build-nanotube n m}) rolls a honeycomb sheet along the chiral vector $n\mathbf a_1 + m\mathbf a_2$: armchair $(n,n)$, zigzag $(n,0)$ or chiral. The unit cell has $4(n^2+nm+m^2)/d_R$ atoms with $d_R=\gcd(2m+n, 2n+m)$ and radius $|\mathbf C|/2\pi$; \code{length} repeats it, or \code{length\_A} asks for a length in \AA. The bond defaults to 1.421~\AA\ for carbon, 1.446~\AA\ for B--N and the sum of covalent radii otherwise (\code{bond} overrides it). Two elements make a BN-type tube with the sublattices alternating. Multi-wall tubes (\code{walls}) add walls about \code{wall\_spacing} (3.4~\AA) apart, with indices chosen to be commensurate. Periodic along the axis by default; \code{finite=true} makes an open tube in vacuum, removes dangling atoms and caps the ends with H, F or Cl (\code{end\_cap}). \code{axis} lays the tube along $x$, $y$ or $z$. The notes give each wall's diameter, the chiral angle $\arctan(\sqrt3 m/(2n+m))$ and, for carbon, whether it is metallic ($(n-m) \bmod 3 = 0$) or semiconducting.
\item \textbf{2D monolayer} (\code{build-monolayer}) makes graphene, hexagonal BN, the buckled Xenes silicene, germanene and stanene (lattice constants and bucklings from DFT: 3.866/0.44, 4.02/0.69, 4.67/0.85~\AA), a 2H or 1T transition-metal dichalcogenide $MX_2$ (MoS$_2$ by default, $a = 3.18$~\AA, as ASE's \code{mx2}) or black phosphorene (puckered, rectangular). Options: $n_a\times n_b$ cells, a rectangular (orthogonal) cell for hexagonal lattices, biaxial \code{strain} in percent, several \code{layers} with AA, AB (Bernal), ABC (rhombohedral) or 2H stacking and an \code{interlayer} distance, and vacuum along $c$ (or a bulk-periodic $c$ with \code{periodic\_c}).
\item \textbf{Nanoribbon} (\code{build-nanoribbon}): armchair ribbons are $N$-AGNR with $N$ dimer lines across (7-AGNR: 14 carbon atoms per 4.26~\AA\ period), zigzag ribbons $N$-ZGNR with $N$ zigzag chains; edges are terminated with H (C--H 1.09~\AA), F, Cl or nothing (\code{termination}, \code{termination\_bond}); \code{finite=true} makes a flake. The notes give the width and, for armchair ribbons, the family $N \bmod 3$ that decides the band gap. ASE's \code{graphene\_nanoribbon} counts armchair widths in pairs of dimer lines.
\item \textbf{Twisted bilayer} (\code{build-twisted-bilayer}) stacks two layers turned by a commensurate angle, $\cos\theta = (3i^2+3i+\tfrac12)/(3i^2+3i+1)$ ($i=1$: 21.79\textdegree, 2: 13.17\textdegree, 3: 9.43\textdegree, \ldots, 30: 1.08\textdegree), in the moir\'e cell of $3i^2+3i+1$ primitive cells per layer; give the angle (the nearest commensurate one is used) or $i$. The top layer may be another hexagonal material (hBN on graphene, a TMD heterobilayer), strained to the bottom lattice with the mismatch reported; the registry at zero twist is AA or AB. The notes give the moir\'e period $a/(2\sin\frac\theta2)$.
\item \textbf{Magic-number cluster} (\code{build-cluster}): Mackay icosahedra and fcc cuboctahedra of 1, 13, 55, 147, 309, \ldots\ atoms (vertices of shell $k$ at $k$ times the nearest-neighbour distance, as ASE's \code{Icosahedron}), regular decahedra (pentagonal bipyramids of five tetrahedra: 7, 23, 54, 105 atoms for 2--5 atoms per edge) and fcc octahedra (\code{shells} atoms per edge: 6, 19, 44, 85, \ldots, as ASE's \code{Octahedron}). Nanoalloys: \code{second\_element} with a \code{fraction} of the atoms placed at random, in the core, in the outer shell or on one side (Janus).
\item \textbf{Molecule} (\code{build-molecule}): H$_2$, N$_2$, O$_2$, F$_2$, Cl$_2$, CO, NO, HF, HCl, H$_2$O, H$_2$S, CO$_2$, SO$_2$, NO$_2$, O$_3$, NH$_3$, PH$_3$, CH$_4$, SiH$_4$, CF$_4$, C$_2$H$_2$, C$_2$H$_4$, C$_2$H$_6$, CH$_3$OH, HCN, H$_2$CO, C$_6$H$_6$ and C$_{60}$ (or names such as water, benzene), with experimental gas-phase bond lengths and angles, or any structure file (XYZ, POSCAR, CIF, \ldots) as the molecule. \code{orientation} keeps the library or file frame, aligns the principal axes of inertia (the long axis on $z$, a planar molecule in the $xz$ plane) or turns it at random; the box around it (\code{vacuum}) can be periodic.
\item \textbf{Molecular packing} (\code{build-packing "H2O 100 CO2 10"}) places molecules (library names, elements or structure files) at random positions and orientations in a periodic box whose size follows from the density, keeping atoms of different molecules at least \code{min\_distance} apart (as Packmol), reproducibly for a seed; it stops with a message when the molecules do not fit. A count of 0 fills the region to the density. Regions confine whole molecules: a box, a sphere or the outside of one, a slab or a cylinder along an axis. \code{mode=solvate} fills the input structure's orthogonal cell around it (the solute), keeping \code{solute\_distance} from its atoms and estimating the free volume on a 0.4~\AA\ grid: \code{build-molecule C60 vacuum=10 periodic=true | build-packing H2O 0 mode=solvate} solvates a fullerene at 1~g/cm$^3$. Filling to a density is best effort (random insertion jams a few molecules short of liquid densities; the notes say how many).
\end{itemize}
Related edits are in \ui{Edit > Chemistry and Defects}. \code{add-adsorbate} places a molecule (library name, element or file) at top, bridge, fcc-hollow or hcp-hollow sites (hcp hollows lie above a second-layer atom) of a slab's top, bottom or both surfaces, its anchor atom (or lowest atom) at a height above the outer layer; one adsorbate at the site nearest a fractional position, all distinct sites of the kind, or a random fraction of them at least \code{min\_separation} apart (the notes give the coverage per nm$^2$). The molecule's $z$ axis points away from the surface, after an optional principal-axes alignment, a \code{tilt} from the normal and an \code{azimuth}. \code{create-antisite} swaps atoms of one element with the nearest (or a random) atom of another, \code{count} times, every swapped atom at least \code{min\_separation} from the others; \code{create-frenkel-pair} moves an atom into an interstitial void or into a split (dumbbell) interstitial along a direction ($\langle100\rangle$ in fcc, $\langle110\rangle$ in bcc metals), leaving a vacancy between \code{min\_distance} and \code{max\_distance} away; \code{saturate-hydrogen} caps under-coordinated atoms with hydrogen or another terminator (F, Cl, \ldots) at a given or tabulated bond length, at most a number per atom, or only the selected atoms; \code{swap-elements} exchanges two elements. \code{stack-layers} (\ui{Edit > Geometry}) puts another structure file on top of this one along $c$, a gap above its top atom, \code{copies} times, each copy shifted laterally (fractional $u$, $v$; e.g.\ $\frac13,\frac13$ for AB stacking) and optionally turned about the normal; both layers can be strained to a common in-plane lattice --- this cell's, the stacked layer's or their average --- with the strains reported, and $c$ grows for the stack and vacuum: \code{build-monolayer mx2-2h na=3 nb=3 | stack-layers graphene.xyz gap=3.4} makes a graphene/MoS$_2$ heterostructure. Per-atom simulation data: \code{set-magnetic-moments} (Bohr magnetons): one value, a value per element (\code{moments="Fe 2.5 O 0"}), a layered antiferromagnet with the sign alternating every \code{period} layers along an axis (A-type), a checkerboard (G-type) or random signs with zero net moment; other orders by selecting a sublattice first (e.g.\ \code{select-expression index \% 2 == 1}). \code{set-charges} (e): one value or a value per element (\code{charges="Ti 2.4 O -1.2"}), neutralised on request by shifting the charges equally or scaling the side in excess, with the total charge reported. \code{set-velocities}: Maxwell--Boltzmann at a temperature, no net momentum and optionally no rotation (for clusters and molecules in vacuum), the kinetic temperature with $3N-3$ (or $3N-6$) degrees of freedom exactly that temperature, in \AA/fs. They travel with the atoms through edits and projects, are expression variables (\code{magmom}, \code{charge}, \code{vx}, \code{vy}, \code{vz}), show in \ui{Atom Info}, and are written to extended XYZ (\code{initial\_magmoms}, \code{initial\_charges}, \code{velo}, as ASE and OVITO read them), LAMMPS data (the charge atom style; \code{Velocities} in metal units, \AA/ps, both also read), CASTEP (\code{SPIN=}) and Quantum ESPRESSO (one species per element and moment, \code{nspin = 2}, \code{starting\_magnetization} the moment over 5~$\mu_B$ as a starting guess); the notes of \code{set-magnetic-moments} give VASP's \code{MAGMOM} line in the atom order. Structures from online databases are searched and downloaded from Python: \code{atomforge.databases.search\_cod(formula="TiO2")} or \code{search\_cod(elements=["Ti", "O"], strict=True)} lists Crystallography Open Database entries (id, formula, space group, cell, mineral), \code{fetch\_cod(9008460)} downloads one (symmetry expanded); \code{search\_materials\_project(formula="TiO2", stable\_only=True)} lists Materials Project entries by formula, elements or chemical system with their energy above the hull, and \code{fetch\_materials\_project("mp-13", conventional=True)} downloads one with its magnetic moments, optionally as the conventional standard cell (spglib); both need an API key in \code{MP\_API\_KEY}. From the command line: \code{python -m atomforge.databases cod 9008460 rutile.cif}, \code{\ldots\ search cod TiO2}. \code{near-cubic-supercell} (\ui{Edit > Cell}) finds the supercell of about a target number of atoms (or any count within a tolerance) closest to a cube, to an fcc or bcc primitive cell (as ASE's \code{find\_optimal\_cell\_shape}), or with the largest shortest image distance, as for point-defect calculations; the notes give the shortest image distance and the inscribed sphere. The primitive fcc cell gives the conventional cube for 4 atoms.

\section{Optional and unavailable builder menus}
The stacking-fault builder is compiled into the desktop menu only with \code{ATOMFORGE_ENABLE_SFE_BUILDER=ON}; the default is ON. Its purpose is to construct faulted configurations, not to calculate a stacking-fault energy. In an enabled build, open \ui{Build > Stacking Faults}, supply a reference with \ui{Use Current Scene} or the source workflow, and click \ui{Detect Structure}. Select a supported Plane, choose \ui{Smallest Unit Cell} or \ui{Orthogonal Cell}, and set Layers (2--96). Click \ui{Generate Sequence}, use the Structure slider to inspect its members, and choose \ui{Use Selected Structure} to adopt one. \ui{Export All Structures} writes the sequence to the specified Folder/Subfolder; \ui{Use Source Folder} supplies a convenient base when available. Validate the stacking geometry and calculate energies externally. The current source build enables this menu; the CLI can export a complete sequence.

\paragraph{Interface Builder.} \ui{Build > Interface Builder} joins two crystals at a coherent interface by matching their surface lattices, the method of Stradi et al., J. Phys.: Condens. Matter 29, 185901 (2017), used by QuantumATK's InterfaceBuilder. Give each crystal (\ui{Load File}, a dropped file or \ui{Use Active Structure}) and the plane it is cut along, $(h\,k\,l)$, with the surface builder; untick \ui{Cut along (h k l)} for a structure that is already a slab (its a and b vectors span the interface). \ui{Layers} repeats each crystal's stacking translation, so close-packed stacking is kept. \ui{Find Matches} rotates B about the interface normal through the given range of angles; for each angle the vectors $i\,\mathbf b_1 + j\,\mathbf b_2$ of B ($|i|,|j| \le$ \ui{Repeats}) are matched to the nearest vectors of A's surface lattice, and pairs of them form interface cells. The strain taking B's cell onto A's is the stretch of the polar decomposition of $F = U V^{-1}$ (so a rotation is not counted as strain), with components $\varepsilon_{11}$, $\varepsilon_{22}$, $\varepsilon_{12}$ in a frame along A's first cell vector and mean $(|\varepsilon_{11}|+|\varepsilon_{22}|+|\varepsilon_{12}|)/3$; cells above \ui{Max strain}, \ui{Max area} or below \ui{Min cell angle} are discarded, and repeats of a smaller cell with no lower strain are left out. The matches are listed with the fewest atoms first (any column sorts the table) and plotted as strain against atoms; the Pareto-optimal ones (no other match has as few atoms and less strain) are joined by a line, and the suggested one (\textbullet) has the lowest strain in per cent plus area / 25~\AA$^2$ among them. For Cu(111) on Ni(111) the 1$\times$1 cell is suggested with $\varepsilon_{11} = \varepsilon_{22} = 2.58\%$, the lattice misfit. \ui{Assembly} sets how the selected match is built: \ui{Strained crystal} B (A keeps its lattice), A, or both (to their average lattice); \ui{Gap}, the distance between the facing atomic layers; \ui{Vacuum} (0 keeps the cell periodic along the normal, with two interfaces each at the gap); \ui{Shift of B} in fractions of the interface cell, which sets the registry of the two crystals; and repeats in the plane. Only the selected match is built, and the preview shows it. The same search is \code{--build interface} (\code{--hklA}, \code{--hklB}, \code{--layersA}, \code{--layersB}, \code{--max-strain}, \code{--max-area}, \code{--repeats}, \code{--min-angle}, \code{--angle-min/max/step}, \code{--strain-on}, \code{--gap}, \code{--vacuum}, \code{--shift}, \code{--pick}, \code{--list}), which prints the table of matches; a small strain does not by itself make a good interface, so compare matches by their interface energy.

\section{Worked study: compare bulk and finite Cu environments}
This exercise connects building, file inspection, and structural analysis. It uses only generated structures and does not require an electronic calculation.
\begin{enumerate}
\item Open \code{examples/cu_fcc.cif}. Inspect its four sites and cubic cell. The cell edge is 3.61 \angstrom. Save a working copy before changing it.
\item Open the supplied \code{cu_host.cif}, or create it by repeating the conventional cell $5\times5\times5$ through Python. It contains 500 atoms. Use this larger periodic host for bulk neighbour statistics.
\item Open \code{cu_sphere.xyz} separately. It contains 336 atoms from the same reference lattice, cut at radius 10 \angstrom. Rotate it and inspect surface sites. The smaller count is caused by the finite shape, not by a different crystal symmetry.
\item Run RDF on the periodic host with Cu as both species, PBC enabled, and no smoothing. Check the first-neighbour peak near 2.553 \angstrom. Begin with a cutoff that is comfortably smaller than the box dimensions.
\item Run RDF on the finite sphere with PBC disabled. Compare raw counts and cumulative coordination before comparing normalised curves: the particle has surface atoms with incomplete neighbour shells and its enclosing vacuum does not define a bulk atomic density.
\item Open \code{cu_ni_alloy.cif}. Verify 350 Cu and 150 Ni atoms, then inspect Cu--Cu and Cu--Ni partial distributions and the SRO table. The unrelaxed substitution changes labels while retaining ideal host positions; it cannot demonstrate size-mismatch relaxation.
\end{enumerate}
Keep the source filenames, cutoffs, species choices, PBC setting, bin count, and smoothing with each plot. If the bulk nearest-neighbour peak moves unexpectedly, first check lattice scaling and units. If coordination falls at the surface of the sphere, inspect its geometric boundary before treating the change as disorder. If the alloy has nonzero measured SRO, compare seeds and finite-size effects before interpreting it as evidence of an energetic ordering preference.

This comparison illustrates why a common visual appearance does not guarantee comparable statistics. The bulk, particle, and alloy answer different questions even though they originate from the same Cu cell. Choose analysis settings according to the geometry and composition of each saved structure.
